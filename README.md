# Yandex Music Playlist Downloader

Скрипт для скачивания плейлиста с Яндекс Музыки в MP3-файлы (для флешки в машину).

## Установка

```bash
pip install -r requirements.txt
```

## Как получить токен

1. Войдите в Яндекс в браузере
2. Перейдите по ссылке:
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
   ```
3. Нажмите «Разрешить»
4. Из адресной строки скопируйте значение `access_token=...` (до символа `&`)

## Использование

```bash
# Показывает список плейлистов — выберите нужный
python download_playlist.py --token ВАШ_ТОКЕН

# Или сохраните токен в переменную окружения
export YANDEX_TOKEN=ВАШ_ТОКЕН
python download_playlist.py

# Скачать конкретный плейлист (kind-номер виден в списке)
python download_playlist.py --token ВАШ_ТОКЕН --kind 3

# Указать папку для сохранения (например, флешка)
python download_playlist.py --token ВАШ_ТОКЕН --output /media/usb/music
```

## Результат

Файлы сохраняются в папку `music/<Название плейлиста>/` в формате:
```
001. Исполнитель — Название.mp3
002. Исполнитель — Название.mp3
...
```

Нумерация сохраняет порядок плейлиста — удобно для автомагнитолы.

## Требования

- Python 3.10+
- Активная подписка Яндекс Музыки (иначе треки будут недоступны для скачивания)
